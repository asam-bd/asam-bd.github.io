Firebase Setup গাইড

ধাপে ধাপে Firebase ও সাইট সেটআপ করুন

ধাপে ধাপে সেটআপ গাইড
১
Firebase Project তৈরি

console.firebase.google.com → Add Project → নাম দিন → Continue

২
Realtime Database চালু

Build → Realtime Database → Create → Test mode → নিচের Rules দিন:

{ "rules": { ".read": true, ".write": "auth != null" } }
৩
Authentication চালু

Build → Authentication → Email/Password Enable → Users → Add User → আপনার email ও password দিন

৪
Config Copy করুন

⚙️ Project Settings → General → Web app → Register → firebaseConfig copy করুন

const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", databaseURL: "https://your-project-default-rtdb.firebaseio.com", projectId: "your-project-id", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123:web:abc" };
৫
দুই ফাইলে Config Paste করুন

index.html এবং admin-panel.html — উভয়তে YOUR_API_KEY ইত্যাদি replace করুন

৬
GitHub Pages Deploy

GitHub → New Repo → Upload files → Settings → Pages → Source: main → Save → আপনার সাইট লাইভ!
